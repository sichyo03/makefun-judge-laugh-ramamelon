One line about office life, under 200 characters, written to be read aloud in
one breath:

> Our office has a suggestion box — it's the shredder, but the intention is there.

The observation is one every office worker nods at — the suggestion box that
changes nothing — and the turn is the reveal that the box and the shredder are
the same machine. The closing clause is the button: the gesture was made, the
suggestions were not read.

## Files

- `main.ts` — the entry program (Node 22, standard library only). It writes
  the line to `/output/entry.txt`.

## Run it

```
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

Outside the grader's container, `MAKEFUN_OUTPUT_DIR` stands in for `/output`.
